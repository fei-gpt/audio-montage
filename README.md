# 视频剪辑工作台

这是一个在自己电脑上运行的视频工作台。选好产品和账号，接入素材文件夹，就可以按配音、音乐或参考视频选镜头，核对预览并导出成片。同一产品共用剪辑总纲和展示类别，各账号分别管理素材、配音历史和剪辑任务。

## 先下载，再启动

1. 打开 [GitHub 仓库](https://github.com/fei-gpt/audio-montage)，点 **Code → Download ZIP**，完整解压到准备长期使用的文件夹。使用 Git 的同事也可以运行 `git clone https://github.com/fei-gpt/audio-montage.git`。
2. 在这台电脑安装 Python 3.10 或更新版本。进入解压后的仓库根目录，Windows 运行 `py -3 -m pip install --target .workbench-deps -r requirements-workbench.txt`，macOS 将开头的 `py -3` 换成 `python3`。剪辑需要 FFmpeg 和 ffprobe，可在根目录运行 `python -m workbench.preflight` 检查环境，macOS 使用 `python3`。
3. **Windows** 双击根目录的 `start-workbench.cmd`。首次启动会在桌面创建「视频剪辑工作台」快捷方式并打开浏览器。桌面没看到快捷方式，或后来移动了文件夹，都可以从当前目录再次双击这个脚本。
4. **macOS** 在根目录运行 `bash 启动工作台.command`，保持终端开启，然后用浏览器打开[本机工作台](http://127.0.0.1:8768/#editing)。

使用 WorkBuddy 的同事可以先下载工作台，再让 WorkBuddy 打开解压后的文件夹，输入「请按本仓库 README 检查本机依赖并启动视频工作台」。新电脑使用自己的素材和服务账号。交接产品时，可另行提供剪辑总纲、展示类别等规则。详细配置见[新电脑安装与交接](HANDOFF.md)。

## 第一次做一条视频

1. 进入 **素材处理**，选择或创建产品和账号，接入本地素材文件夹并扫描。查看素材的展示类别，可用「改类别」修改并确认。长原片需要先挑出有效片段时，进入 **素材整理**，检查候选片段的起止位置和标签，再确认导出。
2. 进入 **视频剪辑制作**，核对当前产品。点击页头的 **剪辑总纲** 可查看或修改这个产品共用的要求。本次任务特有的镜头安排写在剪辑表单的「本批通用剪辑要求」里。
3. 点击 **用配音或音乐剪辑**，选择主音频。第一次试用可以选「音乐」，上传一首音乐或从历史中选取，选择整曲或填写成片秒数，然后生成预览。
4. 在 **剪辑历史** 打开本批记录，查看预览并核对镜头和声音。确认输出后，可在同一行看到成片文件名并下载。遇到「需要处理」，先查看该行原因，调整后在原批次重试。

## 按手头的素材选入口

| 手头已有的内容 | 工作台入口 | 如何使用 |
| --- | --- | --- |
| 一条或多条配音文案 | ElevenLabs 配音 | 每个输入框写一条，整批共用所选音色。生成后可试听，再勾选「用于剪辑」。调用 ElevenLabs 可能计费。 |
| 已生成的配音或本地配音文件 | 视频剪辑制作 → 用配音或音乐剪辑 → 配音 | 默认从当前账号今天和昨天的 ElevenLabs 配音中选择，也可切换为上传本地配音。单条可生成多个候选，多条则每条配音对应一个任务，可共用背景音乐并分别填写补充要求。 |
| 一首主音乐 | 视频剪辑制作 → 用配音或音乐剪辑 → 音乐 | 历史音乐和本地上传都可用。自定义时长从曲首计算，最长到曲尾。可填写必切时间点，留空时可选音乐卡点。 |
| 一个参考视频 | 视频剪辑制作 → 按参考视频剪辑 | 上传参考片，按主体、动作和节奏匹配当前账号的素材库。参考片可以使用不同画幅。 |
| 多组同名 MP4 和 MP3 | 视频剪辑制作 → 批量导入视频＋配音 | 选择或拖入配对文件夹，核对同名片头和配音后，批量建立剪辑任务。 |
| 文稿和参考图、参考音频 | AI 视频生成 | 填写文稿，选择时长和画面比例，添加需要的参考素材。先在对应服务完成配置与授权。 |

## 日常使用

- **素材更新**　同名替换视频后，在「素材处理」重新扫描，核对新版本并确认标签。确认时请核对当前账号和素材文件夹。
- **剪辑要求**　按时长选片时，可用已有类别指定第一镜、第几镜、最后一镜或时间码。例如「第二镜优先用单把光剑旋转」。多条要求用换行或分号分隔。
- **本地数据**　素材、账号历史、任务和服务密钥保存在使用者自己的电脑。其他人从 GitHub 下载程序后，使用自己的文件开始工作。
- **重启**　侧栏的「重启工作台」会中断当前任务。只想查看最新记录时使用页面上的「刷新」。

更多操作可查看[剪辑制作说明](EDITING_WORKBENCH.md)、[AI 视频生成说明](GENERATION_WORKBENCH.md)和[WorkBuddy 功能索引](CAPABILITIES.md)。
